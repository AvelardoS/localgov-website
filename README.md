# 🏛️ localgov-website

**A responsive website mock-up for a local government unit** built using raw web technologies. This project was originally created during my college days as an activity, hands-on exercise, cure curiosity, and master the foundational pillars of web design and Git version control workflows.

🔗 **[View the Live Demo Here](https://avelardos.github.io/localgov-website/)** 

## 📋 Project Context & Design Choice

Our college professor gave us an open design prompt: **build any website layout of our choice** to demonstrate our understanding of frontend structure and version control workflow. 

While the project was a great way to cure boredom, I wanted to challenge myself with a practical, real-world concept. I chose a **barangay website layout** because localized public service platforms require a unique balance of clear information distribution, community-focused announcements, and a clean, trustworthy design aesthetic.

### Core Learning Objectives:

- **Design Freedom & Execution:** Taking a broad academic prompt and narrowing it down to a functional, localized community interface.
- **Web Design Fundamentals:** Implementing clean layout patterns using vanilla code without relying on modern CSS frameworks or templates.
- **Git Command Practice:** Building real-world developer habits by initializing, staging, committing, and pushing updates directly from the terminal.

## ✨ Features

- **Semantic HTML Layout:** Structured cleanly for web accessibility, screen readers, and search engine indexing.
- **Fluid Responsiveness:** Utilizes modern CSS layouts to adapt seamlessly across mobile devices, tablets, and desktop views.
- **Barangay-Centric Design:** Formatted with structural sections ideal for community news, local announcements, and public service information.
- **Interactive UI Elements:** Uses vanilla JavaScript to handle client-side interactive elements (such as navigation toggles or dropdowns).

## 🛠️ Technologies & Tools Used

- **HTML5:** Core page architecture and structural layout.
- **CSS3:** Custom styles, responsive structures, and UI presentation.
- **JavaScript (Vanilla):** Client-side dynamic behaviors.
- **Git:** Version control tracking, commit history management, and command-line deployments.

## 📦 Getting Started & Local Usage

Because this is a static frontend project, there are no heavy packages to download or backend servers to configure.

### Running via Terminal (Practicing Git)
1. **Clone the repository locally:**
   ```bash
   git clone https://github.com
   cd localgov-website
   ```
2. **Launch the project:**
   Simply double-click the `index.html` file within your file manager, or drag it into any open web browser tab.
